What's inside

HEVC decoding

A from-scratch H.265 intra decoder: 8–12 bit, 4:0:0 to 4:4:4, Range Extensions.

Parallel grid tiles

iPhone photos are grids of up to 48 tiles, Samsung's 200 MP files have 768. Natively, they are decoded in parallel.

EXIF / XMP / ICC

Metadata is read without decoding pixels. Rotation, crop and mirror are applied for you.

No unsafe Rust

#![forbid(unsafe_code)], size limits, and fuzzing every night on CI.

Use it in Rust

# Cargo.toml
heifer = "0.1"

let bytes = std::fs::read("photo.heic")?;
let image = heifer::decode(&bytes)?;   // rotation, crop and alpha applied
let rgba = image.to_rgba8();
