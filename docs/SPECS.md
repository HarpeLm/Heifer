# Specifications & references

- ISO/IEC 14496-12 — ISO Base Media File Format (freely available from ISO's public standards list)
- ISO/IEC 23008-12 — HEIF
- ITU-T H.265 — HEVC (free PDF on itu.int) — focus on: NAL units, VPS/SPS/PPS, slice header, coding tree, intra prediction (8.4), transforms (8.6), CABAC (9.3)
- libheif (reference implementation, C++) — https://github.com/strukturag/libheif
- heif-oxide — https://github.com/dan335/heif-oxide
- rust_h265 — https://github.com/roticv/rust_h265
